# Implement Change Skill

Plans and implements focused features, bug fixes, and behavior changes.

Use it for implementation work that requires understanding existing code,
making a minimal change, and validating the result. It follows existing
project patterns over introducing new ones, adds or updates tests for the
change, and checks the final diff for accidental or unrelated edits before
summarizing what changed and what was verified.

See `SKILL.md` for the complete workflow.
