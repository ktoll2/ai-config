# Dependency Change Skill

Guides dependency additions, removals, replacements, and version changes.

Use it when package declarations, lock files, compatibility, migration notes,
or transitive dependencies need review. It checks whether an existing
dependency or platform feature already covers the need, favors the smallest
viable version change, and calls out significant transitive dependencies or
migration requirements. It won't add a dependency solely to avoid writing a
small amount of code.

See `SKILL.md` for the complete workflow.
