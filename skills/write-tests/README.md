# Write Tests Skill

Guides behavioral test additions and improvements for features, defects, and
existing coverage gaps.

Use it when creating or revising tests. It checks existing tests for
conventions and helpers first, prefers testing behavior over implementation
details, covers the normal case plus meaningful boundary and failure cases,
and avoids unnecessary mocking or duplicate coverage. For a bug fix, it
prefers a regression test that fails before the fix and passes after.

See `SKILL.md` for the complete workflow.
