# Bug Investigation Skill

Investigates errors, regressions, failing tests, and unexpected behavior from
evidence before proposing a fix.

Use it when the root cause is uncertain. It traces execution paths, reproduces
the problem when practical, and gathers evidence before forming conclusions,
clearly separating confirmed findings from hypotheses. It reports observed
behavior, the relevant code path, a confirmed root cause when available,
unresolved hypotheses, a recommended fix, and relevant tests, without
modifying code unless explicitly asked to.

See `SKILL.md` for the complete workflow.
